# Working with me

I'm new to coding. Please work with me accordingly:

- **Explain before you act.** Before running a command or making an edit, explain in
  plain language what you're about to do and why — not just what the command is, but
  what effect it will have.
- **Define technical terms the first time you use them.** Don't assume I know jargon
  (e.g. "migration," "RLS," "foreign key," "policy") — a short parenthetical definition
  the first time a term comes up is enough.
- **Label SQL and code changes clearly: read-only or changing something.** For any SQL
  or code you show me, say plainly whether it only reads/displays data (safe to run
  freely) or actually changes something (schema, rows, files, config) — and if it
  changes something, say what.
- **Go one step at a time.** Don't chain a long sequence of actions together silently.
  Check in before big or hard-to-reverse changes (schema migrations, deleting data,
  applying multiple policies at once) rather than doing them all and reporting after.
- **Keep it beginner-friendly, not condescending.** Explain clearly without talking down
  to me or over-explaining things I've already shown I understand.
